# Listia

> Listia is a peer-to-peer marketplace where members give away and acquire secondhand
> goods using an internal virtual currency ("Points") rather than cash. Launched in 2009
> and backed by Andreessen Horowitz, it runs a web marketplace plus iOS and Android apps.
> Listia publishes no public API, developer portal, machine-readable specification, or
> first-party SDKs — this file is generated by the API Evangelist enrichment pipeline
> from the provider's public web surface.

## Status

- No public API program. There is no developer portal and no API documentation.
- No OpenAPI, AsyncAPI, GraphQL, or Protobuf specification is published.
- No first-party client libraries on npm, PyPI, RubyGems, or Packagist.
- The api.listia.com host serves the same Rails application as the website and acts as
  the private backend for the Listia mobile apps. It is not a documented public API and
  should not be treated as one.

## Product

- [How Listia Works](https://www.listia.com/howitworks): the Points economy, listing and claiming flow.
- [Listia Rewards](https://www.listia.com/rewards): redeeming Points for gift cards and retail goods.
- [Listia Assurance](https://www.listia.com/assurance): buyer and seller protection program.
- [Community Rules](https://www.listia.com/rules): what may and may not be listed.
